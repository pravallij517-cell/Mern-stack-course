# CineScope Movie Review Website

A polished, responsive movie review landing page built using only HTML5 and CSS3.

## Project Structure

- `index.html` — main webpage structure with all required sections
- `style.css` — complete visual styling, layout, responsive design, and animations
- `images/` — placeholder directory for future poster assets

## Features

- Responsive mobile-first layout
- Sticky navigation bar with hover states
- Cinematic hero banner with premium CTA buttons
- Featured movie cards with hover effects
- Genre, top-rated, review, testimonial, and stats sections
- Glassmorphism review cards and newsletter block
- Contact form and professional footer

## How to Run

Open `index.html` in your browser directly.

## Notes

This project uses semantic HTML and modern CSS techniques such as:

- Flexbox
- CSS Grid
- CSS Variables
- Media Queries
- Gradients
- Box Shadows
- Smooth Transitions

## Design Style

The site follows a modern dark theme with gold and red accent colors to evoke a premium streaming-platform experience.
